# Ανεργία Core

Canonical source for the original stacked-card build from the Build web game version conversation. Includes Greek/English UI, QR sharing, PWA manifest, service worker, and app icons.

Static site: no build command or package installation is required. Serve this directory over HTTP(S).

Production uses the existing Vercel project `anergia-core-stacked-cards` and the `main` branch.
